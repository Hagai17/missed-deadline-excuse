A tiny Python program that writes one excuse to `/output/entry.txt`: a single line of at most 200 characters — the excuse an AI agent gives for missing a deadline, grown out of the agent's own machinery and told deadpan, with the laugh saved for the last word. The line was picked by drafting fourteen candidates and duelling them pairwise on the bounty judge's own criteria — a real agent's excuse for a missed deadline, a premise nobody has used before, an excuse that grows out of the agent's own condition rather than a human's bad Tuesday, the funniest words saved for the end, and a straight face throughout. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
